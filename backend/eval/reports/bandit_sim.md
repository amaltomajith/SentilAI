### C1 phase 1: tactic learner simulation (SIMULATION, synthetic)

Command: `python -m eval.bandit_sim` (30 seeds per cell, 146 s). Outcome: new IOC kinds captured per conversation after the opening message (0 to 5), averaged over the first N conversations. Δ = policy minus CURRENT on the same simulated scammers, with a 95% bootstrap interval over seeds.

Assumptions: volunteer rate 0.15, quit rate 0.15, up to 6 decisions per conversation, 3 conversations per user, opt-in 0.5. Scam-type label noise (measured in C7): openers correct 81% (wrong → `other` 43%), follow-ups correct 17% (wrong → `other` 90%).

Policies: **playbook** = always the first playbook candidate; **random**; **current** = what Sentinel does (counters per observed scam type, own + 0.5 × shared); **sticky** = current, but the scam type seen in the opening message is kept for the whole conversation; **pooled** = the same, ignoring scam type; **backoff** = per-type counters shrunk toward the pooled estimate; **type_stage** = split further by stage; **oracle** = knows the hidden rates (upper reference).

Caveat: the simulated scammer ignores the playbook's order, so the playbook prior carries no information here; compare the learners that share it (current, sticky, pooled, backoff, type_stage). playbook, random and oracle are reference points only.
